### [Unpatched Cacti Zero-Day Allows Unauthenticated Remote Code Execution](https://www.bleepingcomputer.com/news/security/unpatched-cacti-zero-day-with-public-poc-gives-remote-code-execution/) ⭐️ 7.0/10

A zero-day vulnerability in the Cacti network monitoring platform has been publicly disclosed alongside a working proof-of-concept exploit. The flaw enables unauthenticated remote attackers to execute arbitrary commands on servers running vulnerable instances of the software. Because no official patch is currently available, exposed Cacti installations remain susceptible to immediate remote code execution.

rss · BleepingComputer · Nov 27, 17:06

**「Background」** Cacti is an open-source, web-based network monitoring and graphing tool designed to collect and track operational metrics across IT infrastructure. The platform previously addressed authenticated remote code execution flaws, such as OS command injection risks in versions up to 1.2.30.

**「Impact」** Network and systems administrators running Cacti must restrict external access and monitor traffic to instances, as unauthenticated attackers can leverage the publicly available exploit code to compromise unpatched servers.
